Links and Navigation

Learn how to connect webpages and navigate between sections using HTML.

1. Hyperlinks and File Paths

Hyperlinks are used to connect different webpages or sections within the same page.

                    
                        <a href="https://www.example.com">Visit Example Website</a>

Visit Example Website

To link to different sections within the same website, using ".." escapes the folder and navigates to the parent directory.

                    
                        <a href="../index.html">Go to Main Page</a>

Go to Main Page

3. Navigation

Using an element's ID with a # in a link allows users to jump directly to a specific section of the same page.

                    
                        <a href="#about">Go to About</a>
                        <br> (repeated to demonstrate scrolling)
                        <section id="about">
                            <h3>About</h3>
                            <p>This is the About section.</p>
                        </section>
