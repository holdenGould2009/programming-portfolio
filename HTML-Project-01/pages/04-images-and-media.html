Images and Media

Learn how to add images, audio, and video to webpages using HTML.

1. Images

Images are added to webpages using the <img> element, which requires a source (src) attribute and an alternative text (alt) attribute.

            
                <img src="../media/photo.jpg" alt="A greyscale image of a tree with sun shining behind it.">

2. Audio and Video

Audio and video can be embedded using the <audio controls> and <video controls> elements, respectively. Both elements support multiple source formats for compatibility.

            
                <audio controls>
                    <source src="../media/audio.mp3" type="audio/mpeg">
                </audio>

                <video controls>
                    <source src="../media/video.mp4" type="video/mp4">
                </video>

3. Accessibility

Accessibility means designing webpages so that people with different needs can use them.

Alternative Text

The alt attribute describes an image for people using screen readers and provides text if the image cannot load.

Captions and Transcripts

Captions display spoken dialogue and relevant sounds in videos, helping people who are deaf or hard of hearing. Transcripts provide a written version of audio content. This is often done via <track> along with .vtt files.
