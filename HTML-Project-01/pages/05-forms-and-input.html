Forms

Learn how to create and manage forms for user input on a webpage using HTML.

1. Form Basics

A form allows users to enter information into a webpage. The <form> element groups the inputs together, while <label> describes each input and <input> lets the user enter data.

Basic Form Example

             
                <form> 
                    <label for="username">Username:</label>
                    <input type="text" id="username" name="username"> 
                    <button type="submit">Submit</button>
                </form>

2. Input Types

The type attribute determines what kind of input field is displayed. Different types are designed for different kinds of information.

Common Input Types

  • text: For single-line text input.
  • email: For email address input with validation.
  • password: For password input with masking.
  • number: For numeric input with validation.
  • date: For date input with a calendar picker.
  • checkbox: For selecting one or more options.
  • radio: For selecting one option from a group.
  • submit: For submitting the form.

Code Examples

            
                <input type="text" name="username">
                <input type="email" name="email">
                <input type="password" name="password">
                <input type="number" name="age">
                <input type="date" name="dob">
                <input type="checkbox" name="subscribe"> Subscribe
                <input type="radio" name="gender" value="male"> Male
                <input type="radio" name="gender" value="female"> Female
                <input type="radio" name="gender" value="other"> Other
                <button type="submit">Submit</button>

3. Validation and Accessibility

HTML provides attributes that help ensure users enter appropriate information. Accessibility features also make forms easier to understand and use.

Form Validation

The required attribute prevents a form from being submitted until a field has been filled in. Input types such as email also provide basic validation.

         
            <form> 
                <label for="email-address">Email:</label> 
                <input type="email" id="email-address" name="email" required> 
                <button type="submit">Submit</button> 
            </form>

Accessibility Features

Labels help users understand what information belongs in each field. Connecting a label to an input using the for and id attributes also allows users to click the label to focus the input.

Use clear labels, suitable input types and required fields where necessary. Do not rely on placeholder text alone to describe an input.
