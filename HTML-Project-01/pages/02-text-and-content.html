Text and Content

Learn how to structure, format, and organise text on a webpage using HTML

1. Headings

Headings are used to define the structure and hierarchy of content on a webpage.

                
                    <h3>My Music</h3>

                    <h4>Electronic</h4>
                    <h5>Melodic Dubstep</h5>
                    <h5>Drum and Bass</h5>

                    <h3>Other Genres</h3>

My Music

Electronic

Melodic Dubstep
Drum and Bass

Other Genres

Headings range from <h1> to <h6>, with <h1> being the highest level and <h6> the lowest level.

2. Paragraphs

Paragraphs are used to group sentences together and create blocks of text.

                
                    <p>This is the first paragraph.</p>
                    <p>This is the second paragraph.</p>

This is the first paragraph.

This is the second paragraph.


Paragraphs group related sentences into separate blocks of text. Unlike plain text directly inside the body, paragraphs have their own semantic meaning and default spacing.

3. Text Emphasis

Text emphasis is used to highlight important or stressed parts of the text.

                
                    <p>This is <strong>semantically important</strong> text.</p>
                    <p>This is <em>semantically emphasised</em> text.</p>
                    <p>This is <b>bold</b> text.</p>
                    <p>This is <i>italic</i> text.</p>

This is semantically important text.

This is semantically emphasised text.

This is bold text.

This is italic text.


<strong> and <em> are semantic elements, while <b> and <i> are purely visual.

4. Line Breaks and Horizontal Rules

Line breaks are used to insert a break between lines of text.

                
                    <p>This is the first line.<br>This is the second line.</p>

This is the first line.
This is the second line.


Horizontal rules are used to create a thematic break between sections of content, usually displayed as a horizontal line.

                
                    <p>This is the first section.</p>
                    <hr>
                    <p>This is the second section.</p>

This is the first section.

This is the second section.

5. Preformatted text and Code

Preformatted text is used to display text exactly as it is written, preserving whitespace and line breaks.

                
                    <pre>
                        This is preformatted text.
                        It preserves whitespace and line breaks.
                    </pre>
                
            
                This is preformatted text.
                It preserves whitespace and line breaks.


The code element identifies text as computer code. It can be used inline within a paragraph or for a standalone code snippet.

                
                    <p>This is a <code>code</code> snippet.</p>

This is a code snippet.

Revision Summary

Headings are used to define the structure of a document and its sections.

Paragraphs group related sentences into blocks of text.

Text emphasis can be applied using semantic elements like strong and em, or visual elements like b and i.

Line breaks <br> and horizontal rules <hr> are used to create visual separation between lines and sections of content.
