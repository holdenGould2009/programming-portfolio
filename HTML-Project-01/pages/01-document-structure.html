Document Structure

Learn how a HTML document is organised.

What is document structure?

Every HTML page follows a basic structure that tells the browser how to interpret and display the content.

Why is it important?

A consistent structure makes HTML documents easier for browsers to interpret and developers to maintain.

1. The document type

<!DOCTYPE html> tells the browser to interpret the document using modern HTML standards.

2. The HTML element

<html> contains the entire HTML document.

Try it yourself

Create a new HTML file and identify its document type, root element, head, and body.

Complete example

A basic HTML document looks like this:

            
                <!DOCTYPE html>
                <html lang="en">
                <head>
                    <meta charset="UTF-8"> 
                    <title>Document Structure</title>
                </head>
                <body>
                    <h1>Hello, World!</h1>
                </body>
                </html>

Revision Summary

  • <!DOCTYPE html> declares the document type.
  • <html> contains the entire document.
  • <head> contains metadata and resource links.
  • <body> contains the page content.
  • Headings organise content hierarchically.
